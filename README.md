# Editor LaTeX Sederhana

Editor LaTeX berbasis web sederhana yang menyediakan pratinjau langsung ekspresi matematika menggunakan MathJax.

## Fitur

- Pratinjau waktu nyata dari kode LaTeX
- Mendukung mode matematika inline dan display
- Area teks yang mudah digunakan untuk input
- Output yang dirender ditampilkan di bawah input

## Penggunaan

1. Buka `index.html` di browser web Anda.
2. Ketik kode LaTeX di area teks.
3. Lihat pratinjau langsung diperbarui secara otomatis.

## Contoh

Periksa file contoh:
- `simple sample.txt`: Ekspresi matematika dasar
- `full symbol sample.txt`: Contoh komprehensif simbol dan rumus LaTeX


## Lisensi

Proyek ini bersifat open source. Silakan gunakan dan modifikasi sesuai kebutuhan.
